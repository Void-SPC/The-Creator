# The Labyrinth

Хоррор-игра для Roblox: лабиринт из 100 дверей (001–100). Лобби с рабочим лифтом,
забег идёт в отдельном сервере; самая дальняя дверь — рекорд игрока.

## Как устроено

- Комнаты строятся впереди по ходу игры и убираются позади (`src/shared/RoomPlan.luau`,
  `src/server/World`). Путь идёт «лесенкой» и никогда не налезает на старые комнаты.
- Сектор — 25 дверей. В конце сектора рабочий лифт: только вертикально и только на
  один сектор вперёд. С сектора 2 перед лифтом зал Слепого: детали, три генератора, ворота.
- Существа (`src/server/Game/Entities.luau`): Гул (прячься в шкаф), Смотритель (идёт,
  пока на него не смотрят), Слепой (слышит шаги, крадись).
- Сборщик платы: монеты или 70 % текущего здоровья.
- Предметы: фонарик с зарядом, батарейки, лечебные растения, ключи (только для двери
  своей комнаты), отмычки, свисток.
- Админ-панель для создателей: монеты, предметы, пропуск дверей, вызов существ.

## Проверка и сборка

```
tools/run_tests.sh path/to/luau      # тесты правил и плана комнат, проверка текстов
python3 tools/build_place.py --out out/Workshop.rbxlx
```

Публикация — только вручную через workflow с подтверждением и SHA-256 сборки.
