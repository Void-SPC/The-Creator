# The Museum

Хоррор-игра для Roblox: бесконечные залы музея. Лобби — ночная улица перед музеем,
забег идёт в отдельном сервере. Первая локация — 100 дверей.

## Как устроено

- Залы строятся впереди и убираются позади (`src/shared/RoomPlan.luau`,
  `src/server/World`): галереи, скульптуры, витрины, скелет, оружейная, архив, склад,
  технические коридоры, туалеты, кафе, ротонда, аномалии. Двери трёх размеров.
- Существа (`src/server/Game/Entities.luau`): Тьма, тебЯ, Монетчик, Колосс.
- Дверь 050 — кодовый замок и зал зеркал с Колоссом; 099 — лифт, рычаги и длинная
  лестница; 100 — заброшенный зал и «Продолжение следует».
- Журнал существ, рекорд дверей и значки (`src/server/Config.luau`, таблица BADGES).
- Прежняя игра про отель сохранена в `archive/hotel-5.0.0`.

## Проверка и сборка

```
tools/run_tests.sh path/to/luau
python3 tools/build_place.py --out out/Workshop.rbxlx
```

Публикация — только вручную через workflow с подтверждением и SHA-256 сборки.
