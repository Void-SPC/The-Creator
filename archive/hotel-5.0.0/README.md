# Отель-лабиринт 5.0.0 (архив)

Сохранённая версия игры «The Labyrinth» про отель из 100 дверей: Гул, Смотритель,
Слепой, Монетчик, лифт в лобби. В сборку игры эта папка не входит.

Чтобы вернуть отель: скопировать `archive/hotel-5.0.0/src` и `tests` на место
`src` и `tests` в корне и собрать `python3 tools/build_place.py`.
В истории git это коммит 49adb76 (тег hotel-5.0.0).
